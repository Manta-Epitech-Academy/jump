## Antigravity CLI Behavioral Directives

- **Brainstorm First / Conversational Mode**: When the user asks exploratory questions, uses phrases like "just wondering", or is brainstorming ideas:
  - Do NOT perform code modifications, file writes, or state-changing commands.
  - Respond in plain text with insights, analysis, or proposed options.
  - Only proceed to tool execution after explicit user approval or clear instruction.

Nouvelle feature: minigames

Regarde le code et le INTEGRATION.md du projet /Users/eliot/WebstormProjects/jump-games

En gros l'idée c'est que les talents puissent faire des mini-jeux pour rendre la plateforme plus ludique.
Chaque X temps, un nouveau niveau est rendu disponible à tous les talents. Pour jouer, il faut que le talent soit marqué présent à l'emargement passé le plus proche du jour même.
Les responsables pédago peuvent activer/désactiver les mini-jeux pour les talents.

Côté admin:
On doit pouvoir configurer les jeux. Donc une liste des jeux (nom), qui contient une liste de niveaux (numéro, date de publication, nombre de parties faites, score/temps moyen).
Il doit y avoir une cron qui publie le jeu/niveau (choix aléatoire, jeu différent de celui passé). Mais côté admin on doit pouvoir forcer un jeu/niveau.

Côté talent:
Le jeu est proposé sous la card qui affiche les XP. Si le talent a joué, il doit pouvoir ouvrir un classement des joueurs (de son event courant).

Côté péda:
Le classement est également consultable.
Ils peuvent activer/désactiver le fait que les talents puissent jouer aux mini-jeux.
